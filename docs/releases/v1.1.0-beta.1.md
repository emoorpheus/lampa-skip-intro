**Skip Intro for Lampa 1.1.0-beta.1** — a pre-release for testing: an English interface and an attempted fix for the missing timeline
marks on Android TV. **Checked by automated tests only, not on a TV yet.** The stable version stays
[1.0.0](https://github.com/emoorpheus/lampa-skip-intro/releases/tag/v1.0.0). *Русский текст — ниже.*

### What's new

- **English interface.** The plugin follows the Lampa language (Settings → Interface → Interface language): Russian for Russian,
  English for every other language; Lampa reloads itself after the language is changed. Settings, the button, the countdown,
  notifications, the player menu and Diagnostics are translated. All strings are in one table, `src/05_i18n.js`.
- **Timeline marks.** Own mark style (`.skip-intro-mark`, the look of Lampa 3.4.4) instead of the timeline styles of the Lampa build;
  the end of `video.seekable` when the video reports no finite duration; in the hand-over mode the plugin draws the marks itself
  if Lampa's marks have zero width or no styles.
- **Why there are no marks:** player menu → **Sources** ends with “Timeline marks: 2”, “none — the video length is unknown”,
  “none — the player timeline was not found” or “Lampa draws the timeline marks”; the log gets a `[SkipIntro] Timeline marks: …` line.
- Log messages are in English. Sources, skipping logic, settings and storage keys are the same as in 1.0.0.

### Please test: timeline marks on Android TV

1. Install the beta (see below), restart Lampa and check **Plugin version: Skip Intro 1.1.0-beta.1** in Settings → Skip Intro → Diagnostics.
2. Assign **Keys → Skip menu key** — the player menu needs it.
3. Play an episode with known timestamps (for example *Game of Thrones* S01E01) and show the player panel: are there light-blue marks
   on the progress bar?
4. Press the skip menu key and read the end of the **Sources** line.
5. Report what you saw, that line, your device and whether **Pass timestamps to Lampa (experimental)** is on —
   [issue template](https://github.com/emoorpheus/lampa-skip-intro/issues/new?template=bug_report.md).
   With adb: `adb logcat | grep -F "[SkipIntro] Timeline marks"`.

### Install

Settings → Extensions → Add Plugin: `https://cdn.jsdelivr.net/gh/emoorpheus/lampa-skip-intro@v1.1.0-beta.1/dist/autoskip.js`.
The GitHub Pages address keeps serving the stable version. Self-hosted by IP: add `?v=1.1.0-beta.1` to the URL.
Back to the stable version: put the Pages address (or `@v1.0.0`) back and restart Lampa. Settings, statistics and cached timestamps
are kept both ways (same storage keys).

### Tested

- Unit tests on Node.js 18 and 24: 99 tests. End-to-end tests in the Lampa 3.4.4 web build in Chromium: 80 checks, including the English
  interface with Lampa set to English, marks without Lampa's segment styles and the hand-over mode.
- **Not tested on a TV.** Whether the marks now appear in the Lampa Android app is not confirmed.

### Known issues

- The cause of the missing marks on Android TV is not confirmed; this beta is an attempted fix plus diagnostics.
- Only Russian and English; other Lampa languages get English. Translations are welcome: CONTRIBUTING.md → Translations.
- Samsung Tizen has not been tested on a real device.

Files: `autoskip.js` and `SHA256SUMS` (check with `sha256sum -c SHA256SUMS`). Full list of changes:
[CHANGELOG.md](https://github.com/emoorpheus/lampa-skip-intro/blob/v1.1.0-beta.1/CHANGELOG.md).

**Пропуск заставок для Lampa 1.1.0-beta.1** — предварительный выпуск для проверки: английский интерфейс и попытка исправить
отсутствие отметок на шкале на Android TV. **Проверен только автотестами, на ТВ ещё не проверялся.** Стабильная версия — по-прежнему
[1.0.0](https://github.com/emoorpheus/lampa-skip-intro/releases/tag/v1.0.0).

### Что нового

- **Английский интерфейс.** Плагин следует языку Lampa (Настройки → Интерфейс → Язык интерфейса): русский — для русского,
  английский — для всех остальных языков; после смены языка Lampa перезагружается сама. Переведены настройки, кнопка, обратный отсчёт,
  уведомления, меню плеера и «Диагностика». Все строки — в одной таблице, `src/05_i18n.js`.
- **Отметки на шкале.** Собственный стиль отметок (`.skip-intro-mark`, как в Lampa 3.4.4) вместо стилей шкалы конкретной сборки Lampa;
  конец `video.seekable`, если видео не сообщает конечную длительность; при передаче таймкодов в Lampa плагин рисует отметки сам,
  если у отметок Lampa нулевая ширина или нет стилей.
- **Почему нет отметок:** меню плеера → **«Источники»** заканчивается строкой «Отметки на шкале: 2», «нет — длина видео неизвестна»,
  «нет — шкала плеера не найдена» или «Отметки на шкале рисует Lampa»; в журнале — строка `[SkipIntro] Timeline marks: …`.
- Сообщения журнала — на английском. Источники, логика пропуска, настройки и ключи хранилища — те же, что в 1.0.0.

### Просьба проверить: отметки на шкале на Android TV

1. Установите бету (см. ниже), перезапустите Lampa и проверьте в Настройки → Пропуск заставок → «Диагностика» строку
   **«Версия плагина: Skip Intro 1.1.0-beta.1»**.
2. Назначьте **«Клавиши» → «Кнопка меню пропуска»** — без неё меню плеера не открыть.
3. Включите серию с известными таймкодами (например, *Игра престолов* S01E01) и покажите панель плеера: есть ли голубые отметки на шкале?
4. Нажмите кнопку меню пропуска и прочитайте конец строки **«Источники»**.
5. Сообщите, что увидели, эту строку, своё устройство и включено ли **«Отдавать таймкоды в Lampa (эксперимент)»** —
   [шаблон сообщения](https://github.com/emoorpheus/lampa-skip-intro/issues/new?template=bug_report.md).
   Через adb: `adb logcat | grep -F "[SkipIntro] Timeline marks"`.

### Установка

Настройки → Расширения → Добавить плагин: `https://cdn.jsdelivr.net/gh/emoorpheus/lampa-skip-intro@v1.1.0-beta.1/dist/autoskip.js`.
Адрес на GitHub Pages по-прежнему отдаёт стабильную версию. Свой сервер по IP: добавьте к адресу `?v=1.1.0-beta.1`.
Вернуться на стабильную версию: верните адрес Pages (или `@v1.0.0`) и перезапустите Lampa. Настройки, статистика и кэш таймкодов
сохраняются в обе стороны (те же ключи хранилища).

- На настоящем Samsung Tizen не проверялось.
