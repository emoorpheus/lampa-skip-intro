**Skip Intro for Lampa 1.1.0** — an English interface, timestamps from the video source skipped with the plugin's settings,
timeline marks on Android TV and fixes found on a Tanix TX9. *Русский текст — ниже.*

### Highlights

- **English interface.** The plugin follows the Lampa language: Russian for Russian, English for every other language.
- **Timestamps from the video source** (for example an online balancer that passes its own segments to Lampa) are now skipped by the
  plugin with its own settings: button or auto-skip, segment types, the per-series mode and the countdown. Before, Lampa skipped them
  itself, and in the Android app this failed while the video length was still unknown.
- **One confident database is enough for auto-skip.** If the first database by priority is not sure about a segment and another one is,
  the segment is confirmed (“confirmed by IntroDB”) or the confident timestamps are used.
- **Credits are fitted** to files up to 2 minutes longer or shorter than the database's reference file (was 90 s).
- **Timeline marks state:** the player menu → “Sources” shows “Timeline marks: N” (or why there are none), and
  Settings → Skip Intro → Diagnostics → “Timeline marks (last playback)” shows it without the player menu.

### Fixed

- Timeline marks are shown on Android TV (known issue of 1.0.0) and for timestamps from the video source.
- Color keys on the Tanix TX9 (the WebView reports them with `keyCode` 0 and `ColorF0Red` … `ColorF3Blue`).
- Auto-skip at the very start of a stream: the plugin waits for video data, checks the jump and repeats it (up to 3 attempts).
- Back during the auto-skip countdown cancels the countdown instead of closing the player in the Lampa Android app.
- A few seconds of an earlier start no longer switch intro and recap auto-skip to the button.
- Skipping while the video length is unknown (Lampa's built-in skip and the plugin's own).

Details and evidence (Lampa source lines, logs): [CHANGELOG.md](https://github.com/emoorpheus/lampa-skip-intro/blob/v1.1.0/CHANGELOG.md).

### Tested devices

Manual tests by the maintainer on 2026-11-03:

- **LG OLED65M59LA, webOS 25** (Lampa web app, IntroDB through the proxy) — no problems found.
- **Tanix TX9, Android TV** (Lampa Android app 1.12.4, Lampa 3.4.4) — a test plan run over `adb`: button and auto-skip, countdown and
  Back, “Next episode”, movie credits, per-series modes and offset, own marks, timestamps from an online source, the hand-over mode,
  the English interface; timeline marks are shown. The color keys were sent with `adb`, not pressed on the remote.

The TX9 build had the same code under a pre-release version number; the 1.1.0 file differs from it only in the version string.
Automated: unit tests on Node.js 18, 22 and 24 (CI), end-to-end tests in the Lampa 3.4.4 web build in Chromium.

### Install

Settings → Extensions → Add Plugin: `https://emoorpheus.github.io/lampa-skip-intro/autoskip.js`
(pinned: `https://cdn.jsdelivr.net/gh/emoorpheus/lampa-skip-intro@v1.1.0/dist/autoskip.js`). Self-hosted by IP: add `?v=1.1.0` to the URL.
Then restart Lampa and check “Plugin version: Skip Intro 1.1.0” in Diagnostics.

### Upgrading

From 1.0.0 or 1.1.0-beta: settings, statistics and cached timestamps are kept (same storage keys). If you tested a beta with the
jsDelivr `@v1.1.0-beta.…` address, switch to the GitHub Pages address or `@v1.1.0`.

### Known issues

- Samsung Tizen has not been tested on a real device.
- Files that differ from the database's reference file (for example with an ad inserted at the start): intros are not moved, only
  the credits near the end are fitted (up to 2 min). Use the per-series offset or your own marks.
- IntroDB in TV browsers (webOS, Tizen) needs the [IntroDB proxy](https://github.com/emoorpheus/lampa-skip-intro/blob/v1.1.0/docs/introdb-proxy.md).

Files: `autoskip.js` and `SHA256SUMS` (check with `sha256sum -c SHA256SUMS`).

**Пропуск заставок для Lampa 1.1.0** — английский интерфейс, таймкоды от источника видео пропускаются по настройкам плагина,
отметки на шкале на Android TV и исправления по итогам проверки на Tanix TX9.

### Главное

- **Английский интерфейс.** Плагин следует языку Lampa: русский для русского, английский для всех остальных языков.
- **Таймкоды от источника видео** (например, онлайн-балансера, который сам передаёт сегменты в Lampa) теперь пропускает плагин
  по своим настройкам: кнопка или автопропуск, типы сегментов, режим сериала и обратный отсчёт. Раньше их пропускала сама Lampa,
  и в Android-приложении это не срабатывало, пока длина видео была ещё неизвестна.
- **Для автопропуска достаточно одной уверенной базы.** Если первая по приоритету база не уверена в сегменте, а другая уверена,
  сегмент подтверждается («подтвердила IntroDB») или берутся уверенные таймкоды.
- **Титры подгоняются** к файлам, которые длиннее или короче эталонного файла базы до 2 минут (было 90 с).
- **Состояние отметок на шкале:** меню плеера → «Источники» показывает «Отметки на шкале: N» (или почему их нет), а
  Настройки → Пропуск заставок → Диагностика → «Отметки на шкале (последний просмотр)» — без меню плеера.

### Исправлено

- Отметки на шкале видны на Android TV (известная проблема 1.0.0) и для таймкодов от источника видео.
- Цветные кнопки на Tanix TX9 (WebView передаёт их с `keyCode` 0 и `ColorF0Red` … `ColorF3Blue`).
- Автопропуск в самом начале потока: плагин ждёт данных видео, проверяет переход и повторяет его (до 3 попыток).
- «Назад» во время обратного отсчёта автопропуска отменяет отсчёт, а не закрывает плеер в Android-приложении Lampa.
- Несколько секунд прошлого запуска больше не переводят автопропуск заставки и рекапа на кнопку.
- Пропуск, пока длина видео неизвестна (встроенный пропуск Lampa и собственный пропуск плагина).

Подробности и доказательства (строки исходного кода Lampa, логи): [CHANGELOG.md](https://github.com/emoorpheus/lampa-skip-intro/blob/v1.1.0/CHANGELOG.md) (на английском).

### Проверенные устройства

Ручная проверка автором 2026-11-03:

- **LG OLED65M59LA, webOS 25** (веб-приложение Lampa, IntroDB через прокси) — проблем не найдено.
- **Tanix TX9, Android TV** (Android-приложение Lampa 1.12.4, Lampa 3.4.4) — прогон плана тестов через `adb`: кнопка и автопропуск,
  отсчёт и «Назад», «Следующая серия», титры фильмов, режимы сериала и сдвиг, свои отметки, таймкоды от онлайн-источника, режим
  передачи таймкодов в Lampa, английский интерфейс; отметки на шкале видны. Цветные кнопки отправлялись через `adb`, а не нажимались на пульте.

На TX9 была сборка с тем же кодом под предварительным номером версии; файл 1.1.0 отличается от неё только строкой версии.
Автотесты: модульные на Node.js 18, 22 и 24 (CI), сквозные в веб-сборке Lampa 3.4.4 в Chromium.

### Установка

Настройки → Расширения → Добавить плагин: `https://emoorpheus.github.io/lampa-skip-intro/autoskip.js`
(точная версия: `https://cdn.jsdelivr.net/gh/emoorpheus/lampa-skip-intro@v1.1.0/dist/autoskip.js`). Свой сервер по IP: добавьте к адресу `?v=1.1.0`.
Затем перезапустите Lampa и проверьте в «Диагностике» строку «Версия плагина: Skip Intro 1.1.0».

### Обновление

С 1.0.0 или 1.1.0-beta: настройки, статистика и кэш таймкодов сохраняются (те же ключи хранилища). Если вы проверяли бету по адресу
jsDelivr `@v1.1.0-beta.…`, смените его на адрес GitHub Pages или `@v1.1.0`.

### Известные проблемы

- На настоящем Samsung Tizen не проверялось.
- Файлы, которые отличаются от эталонного файла базы (например, со вставленной в начало рекламой): заставки не сдвигаются,
  подгоняются только титры в конце (до 2 мин). Используйте сдвиг для сериала или свои отметки.
- IntroDB в браузерах ТВ (webOS, Tizen) работает только через [прокси IntroDB](https://github.com/emoorpheus/lampa-skip-intro/blob/v1.1.0/docs/introdb-proxy.ru.md).

Файлы: `autoskip.js` и `SHA256SUMS` (проверка: `sha256sum -c SHA256SUMS`).
