**Skip Intro for Lampa 1.0.0** — the first public release: a skip button and optional auto-skip for intros, recaps, credits and
previews in TV shows, and for end credits in movies. *Русский текст — ниже.*

### Highlights

- Timestamps from TheIntroDB, IntroDB, IntroHater and Aniskip (anime), MKV chapters via TorrServer and your own marks — queried in parallel, combined by priority, cached per episode.
- Auto-skip with a countdown and a trust threshold; «Следующая серия» at the credits through Lampa's playlist.
- Works in the Lampa Android app without a proxy (IntroDB through the app's native request); for webOS, Tizen and browsers there is a small IntroDB proxy (`proxy/introdb_proxy.py`).
- Diagnostics in the settings: source status and response time, «Проверить сейчас», plugin version, statistics.
- Plain ES5 for old TV engines; no dependencies; the interface is in Russian.

### Tested devices

Manual tests by the maintainer on 2026-11-01 (internal build 3.0.1, same code as 1.0.0):

- **LG OLED65M59LA, webOS 25** — IntroDB through the proxy; button, auto-skip, timeline marks and statistics work.
- **Tanix TX9, Android TV** (Lampa Android app) — IntroDB without a proxy; skipping works; timeline marks are not shown (known issue).

### Install

Settings → Extensions → Add plugin: `https://emoorpheus.github.io/lampa-skip-intro/autoskip.js`
(pinned: `https://cdn.jsdelivr.net/gh/emoorpheus/lampa-skip-intro@v1.0.0/dist/autoskip.js`). Self-hosted by IP: add `?v=1.0.0` to the URL.
Then restart Lampa and check «Версия плагина: Skip Intro 1.0.0» in Diagnostics.

### Known issues

- Android TV: segment marks are not drawn on the progress bar, while skipping works.
- Samsung Tizen has not been tested on a real device.

### Upgrading from internal builds 3.x

Version numbers restart at 1.0.0. Settings, statistics and cached timestamps are kept (same storage keys).

Files: `autoskip.js` and `SHA256SUMS` (check with `sha256sum -c SHA256SUMS`). Full list of changes: [CHANGELOG.md](https://github.com/emoorpheus/lampa-skip-intro/blob/v1.0.0/CHANGELOG.md).

**Пропуск заставок для Lampa 1.0.0** — первый публичный выпуск: кнопка пропуска и по желанию автопропуск заставок, рекапов, титров
и превью в сериалах, а также финальных титров в фильмах.

### Главное

- Таймкоды из TheIntroDB, IntroDB, IntroHater и Aniskip (аниме), главы MKV через TorrServer и ваши отметки — запросы параллельно, объединение по приоритету, кэш по сериям.
- Автопропуск с обратным отсчётом и порогом доверия; «Следующая серия» на титрах через плейлист Lampa.
- В Android-приложении Lampa работает без прокси (IntroDB через нативный запрос приложения); для webOS, Tizen и браузеров есть небольшой прокси IntroDB (`proxy/introdb_proxy.py`).
- «Диагностика» в настройках: состояние и время ответа источников, «Проверить сейчас», версия плагина, статистика.
- Чистый ES5 для старых ТВ, без зависимостей; интерфейс на русском.

### Проверенные устройства

Ручная проверка автором 2026-11-01 (внутренняя сборка 3.0.1, код совпадает с 1.0.0):

- **LG OLED65M59LA, webOS 25** — IntroDB через прокси; кнопка, автопропуск, отметки на шкале и статистика работают.

### Установка

Настройки → Расширения → Добавить плагин: `https://emoorpheus.github.io/lampa-skip-intro/autoskip.js`
(точная версия: `https://cdn.jsdelivr.net/gh/emoorpheus/lampa-skip-intro@v1.0.0/dist/autoskip.js`). Свой сервер по IP: добавьте к адресу `?v=1.0.0`.
Затем перезапустите Lampa и проверьте в «Диагностике» строку «Версия плагина: Skip Intro 1.0.0».

### Известные проблемы

- Android TV: сегменты не рисуются на шкале воспроизведения, хотя пропуск работает.
- На настоящем Samsung Tizen не проверялось.

Нумерация версий начинается заново с 1.0.0. Настройки, статистика и кэш таймкодов сохраняются (те же ключи хранилища).

Файлы: `autoskip.js` и `SHA256SUMS` (проверка: `sha256sum -c SHA256SUMS`). Полный список изменений: [CHANGELOG.md](https://github.com/emoorpheus/lampa-skip-intro/blob/v1.0.0/CHANGELOG.md).
